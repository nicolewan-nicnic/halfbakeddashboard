## 🚀 Quick Start (3 Steps)

### 1️⃣ Add Icons to GitHub
```bash
cp *.png your-repo/icons/
git add icons/*.png
```

### 2️⃣ Update App
```bash
cp index.html your-repo/
git add index.html
```

### 3️⃣ Deploy
```bash
git commit -m "Add 9 new recipe icons"
git push origin main
```

**That's it.** Vercel auto-builds within 2-5 minutes.

## 📞 Support

**Icons not showing after deploy?**
1. Clear browser cache: Cmd+Shift+R (Mac)
2. Check PNG files exist in `/icons/` on GitHub
3. Verify icon names match recipe IDs in seed()
4. Redeploy via Vercel dashboard

**Need to modify an icon?**
- Replace the PNG file and push
- Vercel rebuilds automatically
- Takes 2-5 minutes to appear
